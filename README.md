# Calculator

A simple and responsive Calculator application that performs basic arithmetic operations with an easy-to-use interface.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Clear and reset functionality
- User-friendly interface
- Responsive design

## Technologies Used

- HTML
- CSS
- JavaScript

## Description

This project is a calculator application developed using HTML, CSS, and JavaScript. It allows users to perform basic mathematical calculations through an interactive and responsive user interface.
